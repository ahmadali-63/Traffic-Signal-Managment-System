# 🚦 Traffic Signal Management System

A production-ready Full Stack Traffic Signal Management System built with the MERN Stack (MongoDB, Express.js, React.js, Node.js).

## ✨ Features

### Public Features
- Realistic traffic signal with glowing animation
- Digital countdown timer
- Current signal status display (STOP/READY/GO)
- Real-time updates via Socket.IO
- Auto/Manual mode support

### Admin Dashboard
- Start, Stop, Pause, Resume, Reset traffic signal
- Customize light durations
- Switch between Auto/Manual modes
- Real-time analytics and statistics
- History management with search and filters
- Export history as CSV

### Technical Features
- JWT Authentication with role-based authorization
- MVC architecture
- Real-time synchronization with Socket.IO
- Responsive dark theme with glassmorphism
- RESTful APIs with validation
- MongoDB with Mongoose ODM
- Docker support
- Production-ready configuration
